## 关键发现

### 反直觉的结果：增加ARMA阶数使事情更糟

1. **SH指数**：
   - ARMA(0,0)：LB p=0.987（好），Tone显著（p=0.028）
   - ARMA(1,1)：LB p=0.0002（坏），Tone不显著（p=0.404）
   - **原因**：添加AR(1)和MA(1)项改变了动态结构，破坏了原始的良好fit

2. **SZ/HS300/CSI500**：
   - ARMA增加对LB p-值帮助不大
   - 所有阶数下Tone都不显著（p>0.63）
   - **问题可能不是ARMA阶数**

## 诊断结论

**ARMA阶数不是关键问题。真正的问题是：**

1. **参数不稳定性** (Nyblom所有 > 3.51)
   - 所有指数在2017-2024期间系数变化
   - 可能原因：COVID-19、监管变化、市场结构演变

2. **Tone变量本身的有效性**
   - Tone在SZ/HS300/CSI500完全不显著（p≈0.63）
   - 这不是统计问题，而是经济问题
   - Tone可能不真正影响市场，或者测量方法不当

3. **ARCH效应持久** 
   - 所有指数在所有ARMA阶数下都显示ARCH效应
   - 表明方差方程需要加强（GJR-GARCH或更高阶GARCH）

## 建议的下一步

### 短期（改变策略）

❌ **不要再增加ARMA阶数** - 它没有帮助

✅ **策略转换**：
1. 尝试**替代Tone变量**：
   - tone_p90_all_z（总体情感，而非政策特定）
   - 滞后Tone（tone_{t-1}, tone_{t-2}）
   - Tone互动项（tone × 事件虚拟）

2. **改进Tone定义**：
   - 检查RoBERTa分数分布
   - 验证零样本NLI分类的准确性
   - 考虑不同的聚合方法

3. **添加return lags到均值方程**：
   - r_t = α + β*r_{t-1} + ... （momentum/reversion）
   - 可能比ARMA更能捕捉动态

### 中期（模型升级）

4. **滚动窗口估计**（处理参数不稳定性）
   - 分别拟合：2017-2019, 2020-2022, 2023-2024
   - 绘制Tone系数如何随时间变化

5. **制度转换模型**
   - 允许系数基于市场状态（牛市/熊市）变化
   - 更直接处理Nyblom不稳定性证据

6. **改进GARCH规格**
   - GJR-GARCH用于不对称性
   - GARCH(2,1)或更高阶用于持久方差

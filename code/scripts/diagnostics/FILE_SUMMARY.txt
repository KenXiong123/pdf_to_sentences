📊 核心发现速览

  原始模型问题：
    ❌ Ljung-Box自相关：4/4指数失败 (p<0.05)
    ❌ Tone非显著：3/4指数 p>0.6，SH勉强 p=0.028 但负号
    ❌ Nyblom不稳定：4/4指数 > 3.51 (结构性中断证据)
    ❌ ARCH效应：4/4指数 p<0.05

  改进尝试：
    ❌ ARMA(0,0)→(1,1)：更差，LB从0.987→0.0002
    ❌ ARMA(1,1)→(2,1)：SH崩溃，从p=0.028→0.696
    ❌ Tone切换：无效，两个变量同样不显著
    ❌ Return lag：无效，3/4恶化1/4勉强，LB全失败

  根本原因（排序）：
    🔴 优先级1：参数不稳定 (Nyblom > 3.51)
       → 常系数EGARCH违反，需要滚动窗口或regime-switching
    🟠 优先级2：高阶自相关 (ARMA(2,1)不足)
       → 需要ARMA(3,0)或更高，或非线性动态
    🟡 优先级3：ARCH持续 (所有指数p<0.05)
       → 考虑GJR-GARCH或GARCH(2,1)
    🟢 优先级4：Tone真实null
       → 可能通过其他渠道传导
